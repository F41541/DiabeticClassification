# DiabeticClassification
Penelitian ini mengembangkan dan mengimplementasikan model TabNet, sebuah arsitektur deep learning berbasis Transformer, untuk memprediksi risiko diabetes menggunakan data medis tabular. Teknik ensemble learning diterapkan dengan menggabungkan prediksi dari model TabNet, XGBoost, dan Random Forest untuk meningkatkan akurasi prediksi. Dataset yang digunakan berasal dari Kaggle, dengan jumlah 3768 sampel. Model ini dilatih dan dievaluasi menggunakan metrik akurasi, F1-score, dan ROC-AUC, dengan hasil mencapai akurasi 88%, F1-score 0.80, dan ROC-AUC 0.85. Penelitian ini menunjukkan potensi penggunaan model TabNet dalam ensemble learning untuk meningkatkan akurasi prediksi risiko diabetes. Optimalisasi lebih lanjut pada model TabNet dan perluasan dataset diharapkan dapat meningkatkan performa prediksi risiko diabetes di masa mendatang.
